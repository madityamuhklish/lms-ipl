# LMS IPL

Sistem Informasi LMS IPL.

## Teknologi

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Instalasi

1. Clone repository.
2. Copy `config/config.example.php` menjadi `config/config.php`.
3. Sesuaikan konfigurasi database.
4. Import database.
5. Jalankan aplikasi melalui localhost.

## Struktur Branch

- main : branch utama
- develop : branch pengembangan
- feature/* : branch fitur
